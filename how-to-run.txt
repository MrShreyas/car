Build and Run Instructions
==========================

Prerequisites:
- CMake
- MinGW (or another C++ compiler)
- Dependencies (GLFW, Assimp) installed and configured in CMakeLists.txt

Building with CMake:
1. Create a build directory:
   mkdir build
   cd build

2. Generate Makefiles:
   cmake -G "MinGW Makefiles" ..

3. Build the project:
   cmake --build .
   cmake --build . --clean-first // optional 
   cmake --build build

Running the Application:
   ./build/main.exe

Note:
The application expects assets (models, shaders, textures) at specific absolute paths. 
Ensure these files exist at:
- c:/development/car/shaders/
- c:/development/car/models/
- c:/development/car/river_alcove_1k.exr
